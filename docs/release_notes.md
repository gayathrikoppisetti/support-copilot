# Release Notes

## Version 3.4 (July 10, 2026)
- API rate limit for Pro plans increased from 60 to 100 requests per minute.
- Added bulk task import from CSV.
- Fixed a bug where recurring tasks created duplicates on daylight saving changes.

## Version 3.3 (May 28, 2026)
- Invitation links now stay valid for 7 days instead of 3 days.
- Improved search speed for workspaces with more than 10,000 tasks.
- Fixed an Android sync bug that caused tasks to disappear after switching networks.

## Version 3.2 (March 14, 2026)
- Launched dark mode on web, iOS, and Android.
- Added Timeline view for projects.
- Slack integration now supports threaded replies.

## Version 3.1 (January 30, 2026)
- New Guest role with view and comment access only.
- Export now supports JSON in addition to CSV.
